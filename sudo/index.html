So geht's

  1. Fülle jedes Feld mit einer Zahl von 1 bis 6.
  2. In jeder Zeile und jeder Spalte kommt jede Zahl genau einmal vor.
  3. Ebenso in jedem dunkel umrandeten Block aus 3 × 2 Feldern.

Mit Notizen trägst du kleine Kandidaten ein. Doppelte Zahlen werden sofort rot. Tipp deckt das gewählte (oder ein beliebiges) Feld auf. Jeden Tag gibt es ein neues Tagesrätsel.
